# 仕様確認書（初期版）

## 確定事項

- 録音音声を担当者がアップロードし、AIが文字起こし・抽出・要約・登録候補を作る。
- 候補は人間が確認・修正・承認してから登録する。
- メールは担当者が必要分だけ手動登録する。
- Googleカレンダーはシステムからの一方向登録のみとする。
- 一覧・詳細はExcelに近い項目別表示を基本とする。

## 要確認事項

項目定義、承認者、初期インポートの指定フォーマット、Googleカレンダー登録対象、通常利用量の最終値は人間承認で確定する。

## 対象外

電話／CTI連携、録音自動取得、メール自動取込、カレンダー双方向連携、既存予定取込、スマホ専用アプリを含まない。
