# 実装開始ゲート

## 目的

本体実装の開始前に仕様、範囲、承認者、レビュー担当、対象外範囲を明確にし、AIが開発範囲を勝手に広げることを防ぐ。

## 実装開始の承認者

株式会社ルヴィラ 代表 成相政和

## 実装開始前の必須条件

- [ ] 仕様確認書と画面構成確認書が `docs/` に格納されている。
- [ ] 重要前提が `docs/04_important_assumptions.md` に整理され、Phase 1対象外範囲が明記されている。
- [ ] AI役割定義、クロスレビュー手順、セキュリティ・UIチェックリストが作成されている。
- [ ] IssueテンプレートとPRテンプレートが作成されている。
- [ ] 本番反映は人間承認後に限ることが明記されている。

## 実装開始禁止条件

仕様未確定、実装範囲の曖昧さ、対象外範囲の未記載、レビュー担当未定、セキュリティまたはUI影響の不明、人間承認の未記録が一つでもある場合は実装を開始しない。
