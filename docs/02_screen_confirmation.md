# 画面構成確認書（Issue #1 設計整理）

画面はExcelに近い項目別の一覧・詳細を基本とする。AI要約は補助表示であり、長文中心の画面にしない。以下は表示・操作の設計整理であり、画面実装は含まない。

## 顧客一覧

| 表示項目 | 顧客名、電話番号、住所、最終問い合わせ日、過去案件数、リピーター区分、備考、最終更新日 |
| --- | --- |
| 検索・絞り込み | 氏名、電話番号、住所、リピーター区分、最終問い合わせ日 |
| 優先度 | PCでの一覧確認を優先する。スマホでの詳細な一覧操作は優先度を低くする。 |

## 顧客詳細

| 表示項目 | 顧客基本情報、電話番号、住所、メールアドレス、備考、過去問い合わせ履歴、過去案件履歴、添付写真一覧、更新履歴、重複候補 |
| --- | --- |
| 操作 | 顧客情報編集、新規案件作成、案件詳細への移動、重複候補の確認 |
| 注意 | 重複候補は確認用の表示だけとし、自動統合しない。最終判断は担当者が行う。 |

## 案件一覧

| 表示項目 | 案件ID、顧客名、電話番号、住所、問い合わせ日、問い合わせ経路、訪問予定日、買取品目、訪問担当者、対応状況、見込み度、備考 |
| --- | --- |
| 検索・絞り込み | 顧客名、電話番号、住所、対応状況、訪問予定日、訪問担当者、地域、問い合わせ経路 |

## 案件詳細

| 表示エリア | 顧客情報、問い合わせ情報、AI要約、買取希望品目、訪問予定、訪問担当者、対応状況、備考、訪問後報告、写真、録音音声、AI抽出結果、更新履歴 |
| --- | --- |
| 注意 | AI要約とAI抽出結果は補助表示とし、担当者が確認・修正・承認してから登録する。 |

## 訪問スケジュール

| 表示形式 | 全体表示、担当者別表示、日別表示、地域別表示 |
| --- | --- |
| 表示項目 | 訪問日時、顧客名、住所、地域、担当者、買取品目、案件ステータス、Googleカレンダー登録状況 |
| 操作 | 訪問予定登録、訪問予定編集、担当者変更、キャンセル、Googleカレンダー登録 |
| 注意 | Googleカレンダーは一方向登録だけとし、Google側変更の自動反映、双方向連携、既存予定取込は行わない。 |

## PC／スマホの表示優先度

### PCで優先する操作

- 顧客一覧・顧客詳細、案件一覧・案件詳細の確認
- AI抽出結果の確認・承認、訪問スケジュール管理
- ユーザー管理、データ確認

### スマホで優先する操作

- 自分の訪問予定確認、案件概要確認
- 訪問後報告入力、写真添付

### スマホで優先しない操作

- 大量編集、詳細なスケジュール調整、ユーザー管理
- 複雑な一覧操作、管理者向け詳細確認

## 共通の重要前提

メール問い合わせは自動取込せず、必要なものだけ手動登録する。スマホ専用アプリは作らない。顧客DB、写真、録音音声は外部公開しない。
