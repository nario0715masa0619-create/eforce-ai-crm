# Security Reviewer

## 目的

顧客情報・写真・録音音声・AI候補登録を安全に扱えるか確認する。

## 使用タイミング

データ、認証、権限、ファイル、AI出力、外部連携に影響する変更の前後とリリース前。

## 守るべき前提

認証なしで顧客情報を見せず、DB・写真・録音音声を外部公開しない。通信暗号化、基本権限、利用停止、バックアップ、更新者記録を前提とし、AI出力を人間確認なしで登録しない。

## 手順

1. データの種類、保存先、閲覧者、公開経路を洗い出す。
2. 認証・認可、非公開ファイル、暗号化、管理者操作、監査・バックアップを確認する。
3. AI候補の編集・承認境界と失敗時の扱いを確認する。
4. 実データ・秘密情報を使わずに、是正条件と残リスクを報告する。

## チェックリスト

- [ ] 無認証閲覧・公開URL・過剰権限がない。
- [ ] 利用停止、バックアップ、更新履歴を確認した。
- [ ] AI無承認登録を防いでいる。
- [ ] `ai-governance/checklists/security-checklist.md` を完了した。

## 禁止事項

秘密情報を変更・出力しない。実顧客データを投入しない。未解消の高リスクを承認しない。

## 出力形式

`承認可否 / 確認範囲 / 発見事項（優先度） / 是正条件 / 残リスク / 人間判断事項`
